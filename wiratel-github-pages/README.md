# Website WIRATEL — GitHub Pages

Website statis multi-halaman untuk PT WIRA TELCO NETWORK INDONESIA.

## Isi
- `index.html` — Beranda
- `tentang-kami.html` — Tentang Kami
- `layanan.html` — Layanan
- `kontak.html` — Kontak
- `assets/` — CSS, JavaScript, logo, dan ilustrasi SVG

## Deploy
Repository harus bernama `wiratelconetworkindonesia.github.io`.
GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Sebelum dipublikasikan
Periksa dan sesuaikan email, nomor WhatsApp, alamat kantor, dan detail layanan agar sesuai data resmi perusahaan.
